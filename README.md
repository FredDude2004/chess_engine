# Chess Engine

We are going to be making a chess engine in C++. The goal of this project is to build something that
I am proud of and also to build a better understanding of C++ with a hands on approach.

We will be using C++ 23 and trying to follow all the best practices.

Another rule that I have for myself is NO AI USE. AIs can probably one shot this whole project and
there would be no learning and no fun. So I will avoid the use of AI for the most part. I may still
use it to augment my development. I might ask it how to accomplish something in C++ or other general
programming questions (project setup, cmake info, etc.).

But the main resources we will use to build the engine will be the chess programming wiki, video
series and other misc. online resources. We will aim to use high quality written sources, rather
than having an AI generate answers for me.

I am not Anti-AI but I just don't beleive that AI should be used when you are learning. Which is the
goal here.

For the chess engine itself, the goal is to build an engine that can play at the master level, but I
would be happy if we build something that can at least beat me. I'm around 1600 on chess.com and I
think that this shouldn't be to difficult to accomplish.

We will be implementing the rules and the game using bit-boards. After the general implementation
and we get something that is playing at a decent level of strength, I also want to add a NNUE into
the bot to hopefully get some experience with ML and also to make the engine stronger.
